## Research and decisions
Reference pages retrieved 2026-10-22: https://linear.app (show the actual work near the offer), https://www.raycast.com (specific ergonomic interactions), https://wisprflow.ai (direct job-to-be-done and obvious action), https://vercel.com (product/action hierarchy). Browser-control inventory is empty in this environment; local rendering and interaction use Playwright.

The existing application has useful compact work-list/document/queue structures. The landing page has unsupported AST analysis, memory/latency figures, correctness dial, fabricated CLI output, stale branding and excessive mechanical decoration. Replace its composition with the evidence review itself. User granted autonomous creative decisions; no concept approval round is required.

Landing direction: precise evidence desk. Neutral charcoal/white planes, locally bundled Geist, restrained fern-green interaction, a broad working review demonstration, readable source/diff details and a compact three-step setup. No gradients, performance claims, fabricated endorsements or correctness scores. Daylight and evening use both supported through paired themes. The memorable action is switching among changes, checks and missing evidence for the same clearly synthetic session.

## Acceptance criteria

- Every selection opens retained evidence or an unavailable state; caps are visible; keyboard and narrow-screen review work.

## Test plan

Browser-check a complete and partial Story, keyboard traversal, deep links, dark/light themes and reduced motion.

Run only meaningful checks for the final change, record actual outcomes and rerun regressions affected by shared contracts. A documentation/discovery task uses source, link and decision review rather than invented application tests.

## Privacy and security

Treat all captured labels as text; do not load remote assets from evidence.

Retain append-only provenance; unsupported values stay null or an explicit capability state. Captured text is inert untrusted data. Synthetic fixtures contain no real private sessions or credentials.

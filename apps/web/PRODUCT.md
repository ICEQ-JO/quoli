# Traceframe

## Platform and audience
A local-first web application for developers reviewing a coding agent's work on one repository per project. Next.js and TypeScript, operated locally alongside a loopback collector. No paid API is required.

## Purpose
Show what the coding agent did, what changed, and what remains unverified. Recorded session history is the primary record; explanations, metrics, and maps are derived views.

## Positioning and operating context
An evidence workspace used beside an editor in ordinary desktop lighting, with a usable narrow-screen review flow. Clear inspection and explicit uncertainty matter more than promotional claims. The repository is named quoli; the product is Traceframe.

## Current capabilities
The runnable application contains three clearly labeled synthetic sessions, retained activity search, filtering, pagination, source/receipt ordering, inspectable payloads and provenance, deterministic tool request/result links, reported token/cache usage, and capture coverage. An explicit CLI registers real local repositories and captures read-only working-tree baselines/checkpoints with separate code/untracked consent. The dashboard starts with a searchable, grouped session work list. A session review presents recorded requests, capture availability, unambiguously ID-linked tool work, unresolved evidence and a property rail. Needs review is a source-linked queue of recorded capture gaps. Source inspection stays in the review context. Activity, reported usage, capture coverage and bounded before/after file inspection remain available with inferred rename labels and explicit unavailable sides. Real Claude Code collection and a change map remain upcoming.

## Constraints and commitments
Local storage, no outbound session upload, credential-protected local ingestion. Captured text is untrusted data and must never be executed or replayed. Preserve redaction/capture-state markers and null unknowns. A successful command does not establish feature correctness; absent evidence does not establish absence. Never claim access to hidden reasoning, complete capture, precise file costs, or exclusive authorship. No cloud dependency, billing, organizations, or productivity scores in this increment.

## Design authority
The founder explicitly authorized a full dashboard redesign and delegated creative direction. The founder rejected the subsequent spacious ink/cobalt dashboard and requested the familiar craft and density of Linear. Use a compact neutral workspace, readable text and on-demand inspection, with dark and light modes. Preserve behavior and product truth. Documentation is revisable with evidence.
